# ☘ CloverPit — Штаб выживания 2.0

Неофициальная интерактивная панель для учёта забега **CloverPit** на Android и ПК.

**Открыть приложение:** https://wainove.github.io/CloverPit-Companion/

## Возможности
- Учёт долга, внесённых монет, монет на руках, билетов и раундов.
- Проверка риска покупок и рестоков; учёт 8 слотов, экипировки и ящика.
- История действий, резервные копии забега в JSON.
- Экспериментальный OCR скриншота с подтверждением каждого распознанного значения.
- Подготовка отчёта для ChatGPT и системное меню «Поделиться» на поддерживаемых устройствах.

## Установка на Android
1. Открой [сайт панели](https://wainove.github.io/CloverPit-Companion/) в **Chrome**.
2. Нажми **⋮ → Установить приложение** (или **Добавить на главный экран**).
3. Если раньше пользовался локальным HTML-файлом, перенеси сохранение через **История → Сохранить JSON**, затем импортируй его на сайте. Разные адреса имеют разные хранилища.

## Офлайн и точность
После первого открытия основная панель может работать офлайн благодаря service worker. OCR загружает **Tesseract.js 5.1.1** и языковые данные при первом распознавании — для них нужен интернет. Сканирование выполняется в браузере; приложение не синхронизируется с игрой. Числа, правила и рекомендации всегда перепроверяй по игровому экрану. Данные забега сохраняются локально в хранилище браузера; для сохранности используй экспорт JSON.

Это фанатский помощник, **не связанный с разработчиками CloverPit**.
